## Python Tuple Practice Questions

A collection of 30 Python Tuple practice questions designed to strengthen your understanding of tuples and improve your Python programming logic.

The questions start with basic tuple operations and gradually move toward more practical and logic-building problems involving indexing, slicing, loops, unpacking, and nested tuples.

📌 Topics Covered

This practice set covers:

Creating tuples
Empty tuples
Single-item tuples
Tuple indexing
Negative indexing
Tuple slicing
Tuple length
Membership operators: in and not in
Tuple methods: count() and index()
Looping through tuples
Using indexes with tuples
Conditional statements with tuples
Tuple packing
Tuple unpacking
Extended unpacking using *
Swapping variables
Adding items by creating a new tuple
Removing items by creating a new tuple
Converting between tuples and lists
Using built-in functions such as max() and min()
Nested tuples
Combining tuples with loops and conditional statements
📂 Practice Questions
Level 1: Basic Tuple Operations
Create a tuple containing multiple fruits.
Check the data type of a tuple.
Create and print an empty tuple.
Create a single-item tuple and check its type.
Access the first item of a tuple.
Access the last item using negative indexing.
Access a specific item using its index.
Find the length of a tuple.
Check whether an item exists using in.
Check whether an item does not exist using not in.
Level 2: Indexing and Slicing
Extract the first three items from a tuple.
Extract the last three items from a tuple.
Extract items from the middle using slicing.
Get every second item from a tuple.
Reverse a tuple using slicing.
Level 3: Tuple Methods
Count how many times a specific value appears.
Find the index of a specific item.
Find the first occurrence of a repeated value.
Level 4: Looping Through Tuples
Print every item in a tuple using a for loop.
Print tuple items along with their indexes.
Print only even numbers from a tuple.
Print only numbers greater than a specified value.
Level 5: Tuple Packing and Unpacking
Unpack a tuple into multiple variables.
Swap two variables using tuple unpacking.
Use extended unpacking to separate the first, middle, and last values.
Level 6: Modifying Tuples Indirectly
Add a new item by creating a new tuple.
Remove an item by creating a new tuple.
Convert a tuple to a list, modify it, and convert it back to a tuple.
Level 7: Logic-Building Questions
Find the maximum and minimum values from a tuple.
Analyze student marks using nested tuples, loops, tuple unpacking, and conditional statements.
🎯 Learning Objectives

By completing these exercises, you should be able to:

Understand how tuples store multiple values.
Access tuple elements using positive and negative indexes.
Extract portions of a tuple using slicing.
Understand why tuples are immutable.
Use count() and index() effectively.
Loop through tuple data.
Apply conditional logic to tuple values.
Understand tuple packing and unpacking.
Use extended unpacking with *.
Convert tuples to lists when modification is required.
Work with nested tuples.
Combine tuples, loops, and conditional statements to solve practical problems.
🚀 How to Use This Repository
Read the question carefully.
Try solving it on your own.
Run your Python code.
Check whether the output matches the expected result where applicable.
If you get an error, understand why it happened before correcting it.
Move to the next question.

The goal is not just to complete all 30 questions, but to understand the logic behind each solution.

🎯 Goal of This Practice Set

The purpose of this repository is to build a strong understanding of Python Tuples before moving on to more advanced Python concepts and using Python for data analysis.

Rather than memorizing syntax, these exercises focus on understanding:

What data is stored, how Python accesses it, what can and cannot be changed, and how tuples can be used together with loops and conditions to solve problems.
