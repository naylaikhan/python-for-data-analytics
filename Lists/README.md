## 🧠 Concepts in Action

Example of creating a list:

```python
numbers = [10, 20, 30, 40, 50]
```

Accessing an element:

```python
print(numbers[0])
```

Adding an element:

```python
numbers.append(60)
```

Looping through a list:

```python
for number in numbers:
    print(number)
```

Filtering values using a condition:

```python
for number in numbers:
    if number > 20:
        print(number)
```

---

## 📊 Example: Simple Data Analysis

```python
sales = [1200, 800, 1500, 2200, 500, 3000, 1800]

print("Total Sales:", sum(sales))
print("Highest Sale:", max(sales))
print("Lowest Sale:", min(sales))
print("Number of Sales:", len(sales))
```

These concepts form the foundation for more advanced data analysis using tools such as **Pandas** and **NumPy**.
